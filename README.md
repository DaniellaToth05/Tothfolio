# Tothfolio

My personal portfolio site, built as an interactive solar system where each planet is a different section (About, Projects, Skills, Experience, Contact). Includes 3D planet models, a rocket launch intro, and a draggable star map you can navigate around.

Also includes a toggle for a "simple view," a clean, standard one-page layout for anyone who'd rather skip the planets and just see the info quickly.

🔗 [tothfolio.vercel.app](https://tothfolio.vercel.app/)

## Built with

- HTML, CSS, JavaScript
- [model-viewer](https://modelviewer.dev/) for the 3D planet models
- 3D models sourced from [NASA's 3D Resources](https://science.nasa.gov/3d-resources/)
- Deployed on [Vercel](https://vercel.com/)
